We cut CI from 38 to 11 minutes last quarter. The boring part nobody posts about:

- 9 shards, split by test runtime from the last 20 runs, not by file count.
- We broke main twice doing it: both times a test depended on run order.
- Remote caching was a waste of a month for us. Our cache hit rate never passed 31%, because every PR touched the lockfile.

I think most teams reach for caching first and should shard first. The shard config is in the first comment.
